# Mariage à Beaucens

Site d’information, formulaire RSVP et espace organisateur pour le mariage à Beaucens.

## Contenu

- `index.html` : site public prêt pour GitHub Pages.
- `Code.gs` : backend Google Apps Script pour enregistrer les réponses dans Google Sheets.
- `INSTALLATION.md` : procédure de connexion du site à Google Sheets.

## Publication avec GitHub Pages

Dans les paramètres du dépôt, ouvrez **Pages**, choisissez **Deploy from a branch**, puis sélectionnez la branche `main` et le dossier `/ (root)`.

Avant d’utiliser le formulaire partagé, suivez `INSTALLATION.md` pour déployer `Code.gs` et renseigner l’URL Google Apps Script dans `index.html`.
